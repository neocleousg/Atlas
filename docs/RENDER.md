# ΑΤΛΑΣ online στο Render (δωρεάν): οδηγός βήμα-βήμα

Δοκιμαστική εκδοχή με **εικονικά δεδομένα**, για να τον δείξετε ή να τον δοκιμάσει η ΑΑΕΚ από τον browser.
Server στη Φρανκφούρτη (ΕΕ). **Κόστος: 0 €.** Χρόνος: περίπου 15 λεπτά, μία φορά.

## Πώς συμπεριφέρεται η δωρεάν εκδοχή

- **«Κοιμάται»** μετά από ~15 λεπτά που δεν την ανοίγει κανείς. Η πρώτη επίσκεψη μετά την ξυπνά σε
  **περίπου 1 λεπτό**. Μετά είναι γρήγορη.
- **Σε κάθε ξύπνημα ξεκινά καθαρή**: φρέσκα εικονικά δεδομένα με τη σημερινή ημερομηνία. Ό,τι δοκίμασε
  κάποιος χάνεται. Για demo αυτό είναι πλεονέκτημα: δεν χρειάζεται επαναφορά.
- **Δεν είναι για το πιλοτικό.** Πραγματικά δεδομένα φορέων θέλουν μόνιμη βάση, και συμφωνία με την ΑΑΕΚ
  για το πού φιλοξενούνται (GDPR).

## Πριν ξεκινήσετε

- Το PR #1 πρέπει να έχει γίνει **merge** στο `main`.
- Ετοιμάστε:
  - **όνομα χρήστη διαχείρισης**, π.χ. `greg`,
  - **κωδικό διαχείρισης**: μόνο για εσάς, δεν τον δίνετε ποτέ,
  - **κωδικό demo**: κοινός για τους εικονικούς χρήστες `aaek`, `foreas_a`, `foreas_b`. Αυτόν δίνετε στην ΑΑΕΚ.

  Κάθε κωδικός: τουλάχιστον 12 χαρακτήρες, όχι απλή λέξη, διαφορετικοί μεταξύ τους.

## Βήματα

1. **render.com** → **Get Started** → **GitHub**.
2. Όταν το GitHub ρωτήσει σε ποια αποθετήρια θα έχει πρόσβαση το Render: **Only select repositories** →
   **Atlas** → **Install / Authorize**. Όχι «All repositories».
3. Πάνω δεξιά: **New** → **Blueprint** → διαλέξτε **neocleousg/Atlas** → δώστε όνομα, π.χ. `ATLAS demo`.
4. Το Render δείχνει **atlas** (Web Service, Free, Frankfurt). Συμπληρώστε τα τρία πεδία:
   | Πεδίο | Τι γράφετε |
   |---|---|
   | `ATLAS_ADMIN_USERNAME` | όνομα χρήστη διαχείρισης |
   | `ATLAS_ADMIN_PASSWORD` | κωδικός διαχείρισης |
   | `ATLAS_DEMO_PASSWORD` | κωδικός demo |
5. **Apply**. Η πρώτη εγκατάσταση θέλει 3–5 λεπτά.
6. **atlas** → **Logs**. Όταν δείτε `Εικονικά δεδομένα έτοιμα` και `Listening at`, είναι έτοιμο.
   Η διεύθυνση είναι πάνω αριστερά, π.χ. `https://atlas-xxxx.onrender.com`.

> **Αν σας ζητήσει κάρτα ή πληρωμή:** σταματήστε και πείτε μου. Υπάρχει εναλλακτική.

## Έλεγχος (5 λεπτά, σημαντικό)

1. Ανοίξτε τη διεύθυνση. Πάνω πρέπει να φαίνεται «Δοκιμαστική εκδοχή με εικονικά δεδομένα».
2. Συνδεθείτε ως `aaek` (κωδικός demo): πίνακας με 5 προγράμματα, «Δηλώσεις: 3 από 5». Αποσύνδεση.
3. Συνδεθείτε ως `foreas_a`: Πυξίδα, Ανεμόμυλος, Αλυκή. Αποσύνδεση.
4. Ανοίξτε `…onrender.com/diaxeirisi/` με τον λογαριασμό διαχείρισης → **Προσπάθειες σύνδεσης**.
   Η «Διεύθυνση IP» πρέπει να είναι **η δική σας** (Google: «what is my ip»).
   Αν δείχνει `10.x.x.x` ή την ίδια για όλους, **πείτε μου πριν τη δώσετε στην ΑΑΕΚ.**

## Τι δίνετε στην ΑΑΕΚ

- Τη διεύθυνση, τους χρήστες `aaek` και `foreas_a`, και τον κωδικό demo.
- Πείτε τους: «Την πρώτη φορά μπορεί να θέλει ένα λεπτό να ανοίξει. Ό,τι δοκιμάσετε σβήνεται μετά από λίγη ώρα.»

## Ενημερώσεις

Κάθε merge στο `main` ενημερώνει την εφαρμογή αυτόματα.

## Αν κάτι πάει στραβά

| Τι βλέπετε | Τι κάνετε |
|---|---|
| Logs: «Ο κωδικός … δεν έγινε δεκτός» | atlas → **Environment** → αλλάξτε τον → **Save Changes**. Ξαναξεκινά μόνο του. |
| Logs: «Δεν ορίστηκε ATLAS_DEMO_PASSWORD» | Όπως παραπάνω: προσθέστε τον στο Environment. |
| Η σελίδα δεν ανοίγει μετά από 2 λεπτά | Στείλτε μου στιγμιότυπο από τα Logs. |
