# ΑΤΛΑΣ online στο Render: οδηγός βήμα-βήμα

Δοκιμαστική εκδοχή με **εικονικά δεδομένα**, για να τη δοκιμάσει η ΑΑΕΚ από τον browser της.
Server και βάση στη Φρανκφούρτη (ΕΕ). Χρόνος: περίπου 15 λεπτά.

> **Δεν είναι το πιλοτικό.** Πραγματικά δεδομένα φορέων μπαίνουν μόνο όταν συμφωνηθεί με την ΑΑΕΚ
> πού φιλοξενείται ο ΑΤΛΑΣ και υπογραφεί συμφωνία επεξεργασίας δεδομένων (GDPR).
> Σε κάθε σελίδα αυτής της εκδοχής φαίνεται «Δοκιμαστική εκδοχή με εικονικά δεδομένα».

## Πριν ξεκινήσετε

- Το PR #1 πρέπει να έχει γίνει **merge** στο `main`.
- Ετοιμάστε **δύο κωδικούς** (τουλάχιστον 12 χαρακτήρες ο καθένας, όχι απλές λέξεις):
  1. **Κωδικός διαχείρισης**: μόνο για εσάς. Δεν τον δίνετε στην ΑΑΕΚ.
  2. **Κωδικός demo**: κοινός για τους 3 εικονικούς χρήστες. Αυτόν δίνετε στην ΑΑΕΚ.
  Γράψτε τους σε διαχειριστή κωδικών. Δεν εμφανίζονται πουθενά μετά.

## Βήματα

1. Ανοίξτε **render.com** → **Get Started** → **GitHub**. Συνδεθείτε με τον λογαριασμό GitHub σας.
2. Όταν το GitHub ρωτήσει σε ποια αποθετήρια θα έχει πρόσβαση το Render, διαλέξτε
   **Only select repositories** → **Atlas**. Όχι «All repositories».
3. Προσθέστε κάρτα πληρωμής (Account → Billing). Το πακέτο που χρησιμοποιούμε δεν είναι δωρεάν.
   Δείτε την τρέχουσα τιμή στη σελίδα Pricing του Render: είναι λίγα ευρώ τον μήνα για server + βάση.
4. Πάνω δεξιά: **New** → **Blueprint**.
5. Διαλέξτε το αποθετήριο **neocleousg/Atlas**. Το Render διαβάζει το `render.yaml` και δείχνει:
   - **atlas** (web service, Frankfurt)
   - **atlas-db** (PostgreSQL, Frankfurt)
6. Θα σας ζητήσει τρεις τιμές:
   | Πεδίο | Τι γράφετε |
   |---|---|
   | `ATLAS_ADMIN_USERNAME` | Το όνομα χρήστη σας για τη διαχείριση, π.χ. `greg` |
   | `ATLAS_ADMIN_PASSWORD` | Ο κωδικός διαχείρισης |
   | `ATLAS_DEMO_PASSWORD` | Ο κωδικός demo |
7. Πατήστε **Apply**. Η πρώτη εγκατάσταση θέλει 5–10 λεπτά.
8. Ανοίξτε **atlas** → **Logs**. Όταν δείτε:
   ```
   [bootstrap] Δημιουργήθηκε ο λογαριασμός διαχείρισης «greg».
   Εικονικά δεδομένα έτοιμα. Χρήστες: foreas_a, foreas_b, aaek.
   ```
   η εφαρμογή είναι έτοιμη. Η διεύθυνση φαίνεται πάνω αριστερά, π.χ. `https://atlas-xxxx.onrender.com`.

## Έλεγχος μετά την εγκατάσταση (2 λεπτά, σημαντικό)

1. Συνδεθείτε ως `aaek` με τον κωδικό demo. Πρέπει να δείτε τον πίνακα της ΑΑΕΚ με 5 προγράμματα.
2. Αποσυνδεθείτε. Πηγαίνετε στο `/diaxeirisi/` και συνδεθείτε με τον λογαριασμό διαχείρισης.
3. **Διαχείριση → Προσπάθειες σύνδεσης.** Η στήλη «Διεύθυνση IP» πρέπει να δείχνει **τη δική σας IP**
   (τη βρίσκετε γράφοντας «what is my ip» στο Google). Αν δείχνει κάτι σαν `10.x.x.x`, ή την ίδια IP για
   όλους, **πείτε το μου πριν τη δώσετε στην ΑΑΕΚ**: το όριο αποπειρών σύνδεσης θα κλείδωνε όλους μαζί.

## Τι δίνετε στην ΑΑΕΚ

- Τη διεύθυνση `https://atlas-xxxx.onrender.com`
- Δύο λογαριασμούς:
  - `aaek`: βλέπει τον πίνακα όλων των προγραμμάτων.
  - `foreas_a`: λειτουργός φορέα (Πυξίδα, Ανεμόμυλος, Αλυκή). Μπορεί να κάνει δήλωση.
- Τον κωδικό demo.

Ό,τι δηλώσουν μένει στη βάση. Αν θέλετε καθαρή εκδοχή πριν από μια συνάντηση, πείτε μου.

## Ενημερώσεις

Κάθε merge στο `main` ενημερώνει την εφαρμογή αυτόματα (2–5 λεπτά). Τα δεδομένα μένουν.

## Αν κάτι πάει στραβά

| Τι βλέπετε | Τι κάνετε |
|---|---|
| Το Blueprint δεν δέχεται κάποιο «plan» | Το Render αλλάζει κατά καιρούς ονόματα πακέτων. Στη φόρμα διαλέξτε **Starter** για το atlas και το μικρότερο πληρωμένο πακέτο PostgreSQL για το atlas-db. |
| Στα Logs: «Ο κωδικός … δεν έγινε δεκτός» | Ο κωδικός είναι μικρός ή πολύ απλός. Atlas → Environment → αλλάξτε τον → Save. Η εφαρμογή ξαναξεκινά μόνη της. |
| Στα Logs: «Δεν ορίστηκε ATLAS_DEMO_PASSWORD» | Όπως παραπάνω: προσθέστε τον στο Environment. |
| Η σελίδα δεν ανοίγει μετά από 15 λεπτά | Στείλτε μου στιγμιότυπο από τα Logs. |

## Κόστος και διαγραφή

Χρεώνεται όσο υπάρχουν το atlas και η atlas-db. Για να σταματήσει η χρέωση: Settings → **Delete**
και στα δύο. Η διαγραφή της βάσης σβήνει τα δεδομένα οριστικά.
