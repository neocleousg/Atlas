## Δοκιμή σε υπολογιστή Windows (χωρίς τεχνικές γνώσεις)

1. Εγκαταστήστε μία φορά την **Python** από https://www.python.org/downloads/ — στην πρώτη οθόνη τσεκάρετε **«Add python.exe to PATH»**.
2. Στη σελίδα του αποθετηρίου πατήστε **Code → Download ZIP** και αποσυμπιέστε τον φάκελο (π.χ. στην Επιφάνεια εργασίας).
3. Κάντε διπλό κλικ στο **`start_atlas.bat`**. Την πρώτη φορά θέλει μερικά λεπτά.
4. Ανοίγουν αυτόματα ο browser και το αρχείο **`kodikoi_dokimis.txt`** με τους κωδικούς των εικονικών χρηστών (Λειτουργός Φορέα Α, Λειτουργός Φορέα Β, ΑΑΕΚ).
5. Για να σταματήσει, κλείστε το μαύρο παράθυρο.

Τα δεδομένα δοκιμής μένουν μόνο στον υπολογιστή σας (αρχείο `db.sqlite3`) και δεν μεταφέρονται ποτέ σε πραγματική εγκατάσταση.

## Για τον προγραμματιστή

**Τεχνολογία:** Python 3.12, Django 5.2 LTS, PostgreSQL 16, Docker.

### Γρήγορη εκκίνηση με Docker

```bash
cp .env.example .env        # συμπληρώστε DJANGO_SECRET_KEY και POSTGRES_PASSWORD
docker compose up --build   # http://localhost:8000
docker compose exec web python manage.py createsuperuser
```

### Τοπική ανάπτυξη χωρίς Docker (SQLite)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export DJANGO_DEBUG=1
python manage.py migrate
python manage.py seed_demo        # εικονικοί φορείς/χρήστες· τυπώνει τους κωδικούς μία φορά
python manage.py runserver
```

### Έλεγχοι

```bash
DJANGO_DEBUG=1 python manage.py test
```

Οι έλεγχοι στο `core/tests/test_access.py` επιβεβαιώνουν ότι ένας φορέας **δεν** μπορεί να δει ή να αλλάξει δεδομένα άλλου φορέα. Τρέχουν αυτόματα σε κάθε push (GitHub Actions).

## Αρχιτεκτονική

- `core/` — φορείς, ταξινομίες Εθνικής Στρατηγικής, προγράμματα, οθόνες.
- `core/access.py` — **όλοι** οι κανόνες πρόσβασης. Κάθε νέα οθόνη που αγγίζει δεδομένα φορέων πρέπει να περνά από εδώ.
- `accounts/` — χρήστης με ρόλο (`organisation` / `aaek`). Περιορισμός βάσης: χρήστης φορέα ⇔ ανήκει σε φορέα.
- `/diaxeirisi/` — διαχείριση (Django admin) για δημιουργία φορέων και χρηστών.

## Κανόνες

1. Στο αποθετήριο **δεν** μπαίνουν πραγματικά δεδομένα, κωδικοί ή ονόματα προσώπων.
2. Το `.env` δεν ανεβαίνει ποτέ.
3. Η πλατφόρμα δεν αποθηκεύει προσωπικά δεδομένα συμμετεχόντων.
4. Κάθε αλλαγή στην πρόσβαση συνοδεύεται από έλεγχο.

Η ανάπτυξη αξιοποιεί εργαλεία τεχνητής νοημοσύνης, υπό την επίβλεψη και τον έλεγχο του προγραμματιστή.
